# Floral README Design

Reference: `art/floral-reference.png`

Visual language:
- Antique gold botanical textures
- Deep royal/navy blue silhouettes
- Warm cream typography in dark mode
- Ink-blue typography in light mode
- Thin engraved borders
- Floral/peony ornaments
- Animated SVG cursor/star details
- Dark/light mode switching through `<picture>` sources

The README itself contains only Markdown + HTML commonly supported by GitHub README rendering.
No CSS or HTML page is required.
